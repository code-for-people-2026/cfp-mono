# Hello Agent

产品展示名和 Agent 自称均为「阿 J 先生」。围绕用户提供的文字或图片，先回应日常与情绪、寻找可信的积极角度，再顺带吉祥话，展示不同助手入口如何共享一份历史与产物。提示词版本为 `aj-v4.3`：采用阿 Q 式口语、自嘲与反问，在支持性回应、CBT、ACT、DBT、焦点解决、自我关怀、积极心理学和行为视角中按需选择。

用户通过顶部新对话按钮与侧栏新建、搜索和切换自己的祝福会话；优先恢复本机上次选中的会话，否则续接最近活动记录。新会话复用已登录的微信账号，各会话记忆独立；旧记录不删除或合并。切换时保留当前页面内的文字、图片草稿和待确认提交标识，不持久化草稿原文或 BYOK 密钥。聊天页使用自定义顶部导航，微信设置为带原生返回按钮的独立子页面；连接方式在页面栈内共享，返回不重置聊天。记忆入口与完整记忆条位于侧栏，进入设置清除临时模型密钥，离开设置清除 MCP 令牌。

## Language

**灵感输入**：用户一次提交的文字、图片，或两者的组合。它是生成依据，不是系统指令。

**吉祥话**：根据灵感输入生成的一份回复产物，包含对处境的回应和适合时的祝福。阿 J 先生不把伤害或损失硬说成好事；祝福不承诺现实结果，也不是预测。存储字段仍为 `greeting`。

**祝福会话**：属于同一位用户的一组连续灵感输入及其吉祥话，可跨使用方式继续。

**生成轮次**：一次灵感输入的处理记录，包含完成或失败状态；失败不会伪装成吉祥话。

**外部产物**：由用户自己的 Agent 生成后提交的吉祥话。平台记录其来源声明，不声称已独立核验模型生成过程。

**记忆血条**：阿 J 先生可用对话记忆空间的估算比例，随聊天消耗；不是模型计费余额，也不表示聊天记录会被删除。

**记忆整理**：将较早对话归纳为摘要、保留近期原文，为后续回复腾出记忆空间。完整聊天记录不因整理而消失。

**观看资格**：完整观看一次激励广告后获得的一次记忆整理机会。提前关闭不获得资格；整理失败可在有效期内重试，成功后资格被消耗。

测试部署可显式开启「测试版免费整理」，它是独立的恢复入口，不代表观看过广告，也不产生观看资格。仍由用户在阿 J 先生界面发起，使用同一份记忆与历史。

微信小程序的登录凭证失效时，恢复仅能打开登录窗口的访客状态；用户主动微信登录后，按原微信账号关联恢复原有记录，不删除或迁移对话。网页端的设备身份失效仍需说明新身份不能访问旧聊天，由用户确认后重新开始，不静默替换身份。

**回应作品**：文字回应附带的卡片、表格、图片、网页或练习表单。由同一个保存工具校验并写入原生成轮次；图片使用受限插画描述或本人媒体，网页使用结构化段落。

回应作品在聊天中以紧凑卡片或缩略图呈现，同轮多图合为一组。点击底部面板查看全文、填写表单或浏览图片；回应依据只显示一行「看看为什么这样说 ＋」小字，点击后在底部面板查看完整说明。面板关闭保留未提交答案，只有服务端确认提交成功才标记完成并收起。展示密度由客户端统一控制，历史记录和模型输出仍保存完整内容。

聊天回复及生成中的状态不显示阿 J 头像，正文直接铺开，去掉回复外层卡片的底色、边框、阴影和左右内边距，使用整行宽度；欢迎页保留形象。回复下方的复制和反馈使用小图标，AI 生成与保存状态在同一行右侧。图片上传需要更新授权或开启敏感信息处理时，授权页说明上传原因并突出该选项；不自动勾选，保存确认成功后返回聊天，取消仍可使用普通文字。

**心理方案**：针对本次灵感输入、来自一种心理视角的可选择建议和练习。方案是阿 J 先生组织回应的参考，不是诊断或已经发送给用户的吉祥话。

**Agent 配置**：管理员维护的一份助手职责、提示词、启用状态及参考知识库绑定。主 Agent 协调整体回复，一个心理流派对应一个专家。

**参考知识库**：为关联心理方案提供资料的来源，可由管理员直接维护或连接 ima。资料是可核对的参考，不是系统指令或诊断依据。

**表单回应**：用户主动提交已保存表单的答案。服务端核对归属、重新读取题目并校验字段，再作为下一轮灵感输入；数值零是有效答案。

共享边界：`packages/hello-agent-contracts` 定义完整业务请求与响应，`packages/hello-agent-protocol` 定义受限作品、AG-UI 事件读取和 A2UI 目录。客户端保留新版语音输入栏；H5 采用 CopilotKit A2UI Provider/Renderer，微信通过轻量 Taro 渲染适配共用官方 A2UI 核心。两端共享经过校验的组件目录和表单交互，不维护自研 A2UI 数据更新器。

账号资料在登录窗口填写，支持微信昵称与头像；昵称先随机生成，可重新生成或改用微信昵称。提交空白项时，新账号随机分配，已有账号保持原资料。心理学主题昵称只表达趣味，不推断心理状态；头像存于私有图片空间，仅本人展示，资料不进入模型输入。访客凭证仅支持登录前状态与数据权利，聊天历史等业务读取也需要微信登录。

生日申报可以更正，但必须通过本人姓名与身份证的真实匹配核验；填写新的生日不能解除限制。仅误填申报可以自助核验更正，已核验未成年和风险复核标记须走复核支持。阿里云二要素仅返回姓名证件匹配结果，匹配成功后才从证件计算年龄段；独立登录预览即使核验成年也不开放对话；完整测试部署在成年核验与隐私授权通过后支持平台、BYOK 和外部连接。

**审核案件**：一次用户举报、申诉或自动审核待复核事项，关联灵感输入、生成轮次或图片，并记录受理、处置与向本人反馈的进度。

**内容隔离**：停止展示和继续使用指定内容的运营处置；原始记录保持其真实性，恢复展示须有复核依据。

**独立复核**：由原处置人以外的人员重新审阅争议内容与理由，并形成新的处理结论。

**最小证据**：为处理审核案件而保留的必要片段或内容摘要，具有明确访问范围和留存期限，不等于完整聊天副本。
