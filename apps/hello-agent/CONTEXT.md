# Hello Agent

产品展示名和 Agent 自称均为「阿 Q +」。围绕用户提供的文字或图片，先回应日常与情绪、寻找可信的积极角度，再顺带吉祥话，展示不同助手入口如何共享一份历史与产物。提示词版本为 `aq-plus-v4.1`：采用阿 Q 式口语、自嘲与反问，在支持性回应、CBT、ACT、DBT、焦点解决、自我关怀、积极心理学和行为视角中按需选择。

首版用户只看到一条连续对话，自动续接最近记录；不提供新建、选择会话或填写编号的交互。后台与 MCP 仍保留会话模型，兼容已有数据，不删除或合并旧记录。

## Language

**灵感输入**：用户一次提交的文字、图片，或两者的组合。它是生成依据，不是系统指令。

**吉祥话**：根据灵感输入生成的一份回复产物，包含对处境的回应和适合时的祝福。阿 Q +不把伤害或损失硬说成好事；祝福不承诺现实结果，也不是预测。存储字段仍为 `greeting`。

**祝福会话**：属于同一位用户的一组连续灵感输入及其吉祥话，可跨使用方式继续。

**生成轮次**：一次灵感输入的处理记录，包含完成或失败状态；失败不会伪装成吉祥话。

**外部产物**：由用户自己的 Agent 生成后提交的吉祥话。平台记录其来源声明，不声称已独立核验模型生成过程。

**记忆血条**：阿 Q +可用对话记忆空间的估算比例，随聊天消耗；不是模型计费余额，也不表示聊天记录会被删除。

**记忆整理**：将较早对话归纳为摘要、保留近期原文，为后续回复腾出记忆空间。完整聊天记录不因整理而消失。

**观看资格**：完整观看一次激励广告后获得的一次记忆整理机会。提前关闭不获得资格；整理失败可在有效期内重试，成功后资格被消耗。

测试部署可显式开启「测试版免费整理」，它是独立的恢复入口，不代表观看过广告，也不产生观看资格。仍由用户在阿 Q +界面发起，使用同一份记忆与历史。

设备身份失效时必须说明新身份不能访问旧聊天，由用户确认后重新开始；不静默替换身份，不删除服务器上的旧聊天。

**回应作品**：文字回应附带的卡片、表格、图片、网页或练习表单。由同一个保存工具校验并写入原生成轮次；图片使用受限插画描述或本人媒体，网页使用结构化段落。

**心理方案**：针对本次灵感输入、来自一种心理视角的可选择建议和练习。方案是阿 Q +组织回应的参考，不是诊断或已经发送给用户的吉祥话。

**Agent 配置**：管理员维护的一份助手职责、提示词、启用状态及参考知识库绑定。主 Agent 协调整体回复，一个心理流派对应一个专家。

**参考知识库**：为关联心理方案提供资料的来源，可由管理员直接维护或连接 ima。资料是可核对的参考，不是系统指令或诊断依据。

**表单回应**：用户主动提交已保存表单的答案。服务端核对归属、重新读取题目并校验字段，再作为下一轮灵感输入；数值零是有效答案。

共享边界：`packages/hello-agent-contracts` 定义完整业务请求与响应，`packages/hello-agent-protocol` 定义受限作品、AG-UI 事件读取和 A2UI 目录。客户端保留新版语音输入栏，作品渲染器只消费已校验的目录组件。
