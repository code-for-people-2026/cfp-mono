# Payload 管理 Agent 配置，显式 seed 初始化，知识库按专家绑定

Agent 提示词和启停状态属于管理员维护的产品配置，保存于同一 Payload 的 `agent-configs`，不放入访客仓库。每个受支持的心理流派有一个唯一标识，主 Agent 使用保留的 coordinator 标识；管理员可以编辑完整提示词、启停和绑定知识库，主 Agent 不能停用或删除。增加新的流派标识仍需扩展共享回应协议。每轮开始读取配置快照，仅注册已启用的专家，修改从下一轮生效。执行记录保存配置 ID / 更新时间，通用安全和工具权限约束由代码附加，不受提示词编辑改变。

默认提示词只用于 `seedAgents`。新本地库的 db:init 与显式 db:seed 调用同一个 seed；正式部署在迁移后执行 db:seed。seed 按唯一标识补缺，不覆盖已有记录，不生成管理员、聊天样例、知识库或凭证；删除的默认流派在下次显式 seed 时会补回，长期停用应使用启用开关。普通请求不偷偷创建配置，漏做 seed 时生成与就绪检查明确失败。外部 MCP 的独立提示词仍由其版本契约提供，不向外部客户端暴露内部专家配置。

`knowledge-bases` 支持后台参考资料和腾讯 ima，只允许管理员维护。每位专家最多绑定两个启用的知识库；只有实际咨询该专家才读取。ima 通过固定官方地址的 search_knowledge 接口查询主 Agent 提供的短方法关键词，长组合词无结果时最多两次缩短关键词重试，取最多三个结果。没有搜索正文片段时调用 get_media_info，再读取官方返回的原文地址或笔记 API，支持 PDF（最多 40 页）、DOCX、网页及纯文本；摘取相关段落交给专家，不宣称读取了整个文档。订阅库拒绝原文权限时记录受限状态，不绕过权限或把标题当正文。资料、提示中的例子和搜索结果是参考素材，不能变更系统权限。连接失败给专家明确的缺失说明，可以继续普通支持性回应。

ima Client ID 与知识库 ID 可编辑；API Key 通过虚拟输入字段更新，以服务端 Payload secret 派生密钥进行 AES-256-GCM 加密。密文只对内部读取上下文可见，管理员接口也不回显；空白输入保留密钥，清除操作显式执行。不启用知识库版本历史，避免另外保存凭证副本；更换 Payload secret 前需要解密迁移或重新录入 ima 密钥。API 请求禁止重定向、固定 ima HTTPS 主机、8 秒超时、1 MB 响应上限；原文只接受官方返回的 ima.qq.com、mp.weixin.qq.com 或 \*.myqcloud.com 的 HTTPS 地址，6 秒超时、5 MB 上限，不向原文域名发送 ima 凭证；单库检索与读取总计 16 秒。供应商异常原文不进入日志或模型上下文。数据库备份仍按私密数据保护。

官方协议依据：腾讯发布的 [ima 技能包 1.1.10](https://app-dl.ima.qq.com/skills/ima-skills-1.1.10.zip) 中 knowledge-base/references/api.md；配置入口为 [ima OpenAPI](https://ima.qq.com/agent-interface)。连接检查使用 get_knowledge_base 验证所填 ID 的读取权限；2026-10-13 真实接口核对后，统一解析 code/data/info_list/highlight_content（成功 code=0），修正旧文档 retcode 的错误假设。自动测试使用符合此契约的 HTTP 边界夹具；没有真实 ima 凭证时不把夹具通过称为已连通用户的知识库。

每轮专家执行事件保存了当时提供的资料节选、检索词、权限或格式失败说明以及 referenceId。专家提交方案必须显式列出 usedSourceIds，只能声明本轮实际提供正文的资料；成功提交的工具响应确认后才计入“声明引用”。Payload 的每轮记录内展示检索结果、正文节选与声明引用，管理员专用接口验证登录，访客响应不暴露执行记录、API Key 或原文临时签名 URL。旧轮次没有资料上下文时明确提示缺失，不补造历史依据。引用声明不等于最终回答的准确性，应结合节选核查。
