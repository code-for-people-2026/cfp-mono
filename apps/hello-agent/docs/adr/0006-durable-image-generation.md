# 生图任务归生成轮次，文件归本人私有媒体

主 Agent 在用户明确提出生图需求时调用独立 `generate_image` 工具，使用北京百炼万相 wan2.6-t2i，一轮一张。工具不提供给心理专家。DeepSeek 继续负责对话和编排。

先落库提交状态，再请求供应商；取得任务编号后持久化再轮询。回执不明不自动重提。下载、审核服务暂不可用或保存失败可由用户继续取图，复用原任务；确定风险、未知提交回执或任务过期不恢复。使用已有会话锁，并为生图单独预留每日额度，避免重复收费和额度绕过。

生成像素经阿里云内容安全审核通过后，保留 AIGC 来源、增加可见标识、转为有大小上限的 JPEG，存入已有私有 OSS 媒体。客户端只持有受本人鉴权保护的应用图片地址。来源和审核摘要随媒体保存、导出与删除。沿用 ADR-0002 的凭证临时安排和私有读取边界；不自动接入尚未合并的内容安全运营后台。

代价是供应商、审核和 OSS 任一不可用都会阻止本轮完成；没有后台队列，进程中断后由用户继续取图。登录、年龄核验和隐私授权门禁仍由现有模块执行。
