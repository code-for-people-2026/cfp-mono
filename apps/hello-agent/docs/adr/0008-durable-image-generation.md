# 文生图由独立工具执行，任务和图片归现有 Payload / OSS

2026-10-14。延续 ADR-0002、0003、0004、0005 和 0007。

DeepSeek 负责理解用户需求及组织回应，`generate_image` 调用北京百炼万相 `wan2.6-t2i`。每轮只提交一张图片，持久化任务编号后再轮询；任务下载或转存中断时由用户“继续取图”恢复，复用原任务，不重新计费生成。提交回执丢失时保留 `submitting`，禁止自动重提，交由管理员核对供应商记录。

返回文件须经过格式/体积限制、AIGC 标识及独立图片审核，再保存到现有私有 OSS；数据库保存对象引用、来源和轮次关联。模型只能拿到媒体编号，客户端通过已有鉴权图片路由展示与下载。供应商临时 URL 不写入作品、不返回客户端。保存以身份和轮次唯一键幂等，隔离、导出、撤回及删除覆盖生成图片。

代价是需要单独的百炼密钥与图片审核服务，并受任务/下载链接 24 小时有效期限制。第一版只提供文生图，不提供图像编辑、多图生成或公众分享链接。仍采用请求内执行，超时后明确恢复；后续如要后台自动完成，应新增持久队列而非仅延长 HTTP 超时。
