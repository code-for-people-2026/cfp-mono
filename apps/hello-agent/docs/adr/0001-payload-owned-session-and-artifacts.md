# 会话与吉祥话归 Payload 管理，ADK 只拥有执行机制

平台助手、BYOK 和外部 Agent 必须看到同一份祝福会话与产物，因此产品状态统一存入 Payload；内置 ADK 的 `BaseSessionService` 使用 Payload 适配器，不再引入另一套 ORM 或内存事实来源。ADK 执行会话按轮次隔离，产品历史由共享业务模块提供，外部模式无需创建 ADK 会话。

本地示例选择独立 SQLite 与受限图片字段，避免为验证架构提前部署 Postgres、对象存储和任务队列。代价是需要自己维护一个小型 SessionService，并且不能宣称具有分布式长任务恢复能力；后续扩大使用时可替换存储实现，但业务产物与授权仍归同一业务模块。
