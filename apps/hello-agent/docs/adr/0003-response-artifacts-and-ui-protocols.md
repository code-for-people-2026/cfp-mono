# 回应作品归领域模块所有，以 AG-UI 承载 A2UI

模型经保存工具提交受限的回应作品，领域模块统一校验和持久化；AG-UI 1.0 传递生成生命周期及已保存结果，A2UI v0.9.1 使用项目自有目录描述界面。选择共享契约与 Taro 渲染适配，保留 H5 和微信小程序两端，代价是只支持目录中明确声明的组件及数据路径，不承诺实现任意 A2UI 目录或网页代码。

不把模型生成的任意 HTML、脚本或远程图片 URL 当成可信执行内容。网页由结构化段落生成，图片由受限几何描述栅格化或引用自己的媒体；如果未来接入摄影级绘图服务，应作为新的图片生成能力接入，同样经过归属校验。表单 action 只引用已保存原表单，服务端重新取题目、校验所属用户与会话、字段及范围后生成下一轮。

此决策延续 ADR-0001：Payload 仍拥有产品记录，ADK 只负责本轮执行，REST 和外部 MCP 使用同一保存规则。传输断开不撤销已保存结果，客户端通过历史恢复；目前模型供应商仍使用非流式工具调用，所以进度实时发送、结果在校验保存后发送，不宣称逐 token 生成。
