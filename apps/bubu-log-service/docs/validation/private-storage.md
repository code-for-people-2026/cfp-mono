- 恢复后真实 HTTP 验证通过：原 8 个账号与 5 个家庭只读导出/日历数据读取、4 个历史图片引用盘点、双层鉴权、只读写保护；新建合成家庭验证正确及错误密码、昵称、活动/日报写入、私有图片引用替换、账号删除保留家庭事实、家庭清理与幂等。拒绝探测仅使用事先确认不存在的随机 ID。
