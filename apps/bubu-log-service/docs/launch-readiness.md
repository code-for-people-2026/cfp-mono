# 卜卜日记上线准备

关联 [#407](https://github.com/code-for-people-2026/cfp-mono/issues/407)，依赖体验版 [#406](https://github.com/code-for-people-2026/cfp-mono/pull/406)。本文件是工作记录，不是上线批准。

## 已实现的边界

- 本人、监护人、AI、照片、群采集分别选择；撤回以后服务器停止后续处理。
- 受保护图片解码、元数据移除、方向校正、2048 像素边界、每宝宝鉴权、加密落盘。
- 图片检测门、独立供应商披露、持久配额、失败关闭以及 AI 输入证明已实现，见 [ADR 0010](adr/0010-private-image-review.md)。历史照片继续按权限查看；配置存在不代表生产检测已验收。
- 账号与家庭两种删除意图、近期登录、逐字确认、独立日志、冻结、重试和恢复重放。
- 菜单内隐私设置、请求和投诉、导出和删除状态；Payload 内按范围查看及回复。
- 危险描述固定提示、延迟群消息时间标记、AI 回复标识。不会根据“没记录”推断异常。
- 已完成的原文、未关联照片的保留清理。未完成任务延期会出现在维护报告，不能算作清理成功。

## 实际部署前必须完成

1. 确认卜卜日记的运营主体、隐私联系渠道、保存期限和处理地域。Hello Agent 的批准不等于本产品的批准。
2. 将原 Payload 后端及数据库完整迁移到境内，保留原表和业务逻辑；核对快照、增量、约束、引用和统计。切换前确认所有旧写入入口处理方式。
3. 历史公共 Blob 图片须复制、验证、改为鉴权读取，并撤销旧公开对象；仅新增图片代理不足以完成此项。
4. `apps/bubu-log-core` 已实现原表的家庭及本人账号生命周期和独立私有访问，已通过真实原库快照与原 Payload HTTP 协议核验，见[存储验证](validation/private-storage.md)。遗留 BabyProfile 的归属已由负责人确认并写入私密配置；真实部署尚未切换，在完成前，现体验版不能视为已支持家庭全量删除。
5. 在生产数据目录以外预建权限受限的 `BUBU_DELETION_LEDGER`，配置独立保存的 32 字节 `BUBU_MEDIA_ENCRYPTION_KEY`。现有照片升级先备份，停止所有写入后运行 `scripts/privacy-maintenance.ts migrate-media` 核对；显式 `--apply` 才修改。
6. 停写加密备份、隔离解包、运行状态与定时器模板已实现并完成[隔离演练](validation/operations.md)。仍须确认生产期限并安装定时器、完成独立密钥/清单异地保全、完整应用恢复、外部通知与证书续期。默认维护脚本为 dry-run，不能在运行中的同一个数据目录启动第二个进程。
7. 核实实际 AI/图片供应商的处理约定和地域；图片检测能力与尿布等照护图片误判的申诉流程。检测代码已有，生产凭证、服务启用和照护图片适用性仍未验收；尚未把家庭照片交给检测供应商。关闭未完成披露的语音功能。
8. 微信后台真实填写隐私指引、服务类目与备案等适用材料，平台实际审核；真机验证微信登录、照片上传/下载、授权拒绝与撤回、导出/注销。微信支付继续关闭。

## 非敏感历史盘点（2026-10-24）

只读核实：原 PostgreSQL 17.11，约 15 MB；Baby 5、BabyUser 7、Activity 2138、DailyStat 97；Activity/Baby/BabyProfile 的照片或头像字段各有一个非空引用。源地域为 us-east-1。这里只是当前盘点，迁移时必须重新核对；未更改或删除真实记录。

## 配置

参见 `.env.privacy.example`；不得提交真实密钥或用示例主体冒充正式政策。文案版本随配置改变，旧授权需要重新阅读。生产读取拒绝未加密对象，先执行离线迁移，不能直接替换运行镜像。
