# 身份状态独立持久化，既有照护数据保留原归属

使用独立卜卜日记服务与 Payload SQLite sidecar 保存身份、凭证摘要、授权、邀请、群绑定和审计；原 AppUser、Baby、BabyUser、Activity、DailyStat 仍由原 Payload 维护，旧账号通过原 NextAuth 凭证流程核验，业务读取通过服务器持有的专用 CMS 凭证适配。这样可保留旧数据结构与统计语义，也不需要继承 Hello Agent 的产品身份、心理领域或修改旧仓库；代价是需要旧服务可用，以及两个数据库之间显式的恢复流程。

新家庭以已提交的初始化日志和服务端派生的稳定旧记录 ID 恢复部分成功；完成后不再重建旧关系，防止撤权被“重试”覆盖。Sidecar 多行变更使用真正的 Payload/SQLite 事务；跨旧后端 HTTP 写入不属于这个事务，下层 MCP 必须建立自己的幂等写入与恢复协议。已公开的旧照片 URL 不可能由新身份层追溯撤销；新 API 只返回按宝宝鉴权的代理路径，后续附件使用独立私有存储。
