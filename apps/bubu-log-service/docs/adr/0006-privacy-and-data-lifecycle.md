# ADR-0006：隐私选择与数据生命周期

状态：实现中，见 #407。依赖身份、MCP、私人对话、运营和权益模块；不替代照护事实模型。

本人处理选择与宝宝监护授权分别保存在隐藏的 Payload 集合。版本由完整披露文案计算。身份权限与隐私授权是相交条件，不能借授权获得另一个宝宝的权限。读取、写入、图片和模型调用都在服务器复核；撤回作废委托凭证。未作出本人选择时，登录回执不读取家庭名单。宝宝管理权限不等于已经声明监护身份。

图片按宝宝隔离，经解码、方向校正、缩放、去除元数据后，以 AES-256-GCM 加密落盘。密钥与生产数据目录分离。旧明文对象仅由停止服务、持有独占锁的显式迁移工具处理，线上读取没有明文回退。附件 ID 保持稳定，照片哈希随标准化变化；原始请求指纹仍用于防止重复请求换内容。

注销本人账号与家庭硬删除是不同操作。服务先签发短期确认意图；本人在新近登录状态下输入完整确认文字，才能进入删除。先持久化独立于数据库快照的删除清单，再冻结访问，随后清理上游、侧车与图片；失败留待重试。恢复备份必须重放当前清单，包括快照中已经标为完成的任务及没有元数据的孤立对象。清单丢失或损坏要停止处理，不生成空清单继续运行。清单是权限受限的最小防复活记录，其哈希链用于发现损坏，不声称能抵抗同时控制整份文件的攻击者。

注销保留家庭共同照护事实，不注销原版账号。若注销者是当前授权监护人，宝宝处理暂停；拥有宝宝管理权限的另一位成年监护人需要重新作出声明。聊天中的“删除记录”仍是可撤销的业务操作，不能代替隐私硬删除。

危险文字先触发固定安全提示，独立于模型供应商；不会由此自动创建照护事实。风险提示只保存类别、来源类型与时间，不复制照片和原文。群采集保留原消息与发现时间，不代表实时监护。运营核对有明确范围、理由和审计；账号级隐私请求仅管理员可处理，宝宝级请求仍受宝宝范围约束。

保留期限来自部署配置，未确认时不启用。已完成原文到期清理，结构化事实与去重标识保留。未确认的活动任务计入延期异常，不能伪称已清理；此项需要运营处理和继续完善。当前阶段尚未完成原库境内切换、历史公开对象撤销、加密备份自动化和平台材料验证，所以不能据此宣布具备上线条件。
