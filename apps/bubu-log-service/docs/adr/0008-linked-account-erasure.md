# ADR 0008：注销覆盖已绑定原账号，且不能恢复旧授权

状态：实现中，尚未部署。关联 #407，依赖 ADR 0006/0007。

## 问题

仅清除 sidecar 身份后，原 User/BabyUser 仍允许旧密码登录；系统会创建新的身份并继承原家庭权限。私聊虽已删除，旧授权却能恢复。本人资料导出也缺少原账号的非秘密资料。

本决策取代 ADR 0006 中“不注销原版账号”的旧范围；旧确认不能执行扩大后的注销。

## 决策

- 原账号归属只能从已证明的服务端身份及别名映射取得，不能由删除请求提供 User ID。确认时将全部稳定原 User ID 和 sidecar 身份写入独立删除清单，在任何远端删除前冻结。旧账号登录和绑定均在解析身份前检查该清单；恢复旧库或映射不能恢复权限。
- 注销范围明确包含已绑定原版账号；确认文字与后果由服务端返回。确认意图使用新契约版本，旧意图须重新阅读；绑定关系变化也须重新确认。不得把原来“只注销小程序”的确认扩大执行。
- core 的 AccountLifecycle 在事务里清除该人的 User 资料、Account/Session 凭证和 BabyUser 关系，清空 AuditLog 的 user_id，清理相关无外键 Payload 锁。保留所有 Baby/Activity/DailyStat、必要照护来源及其他照护者。即使这是最后一名成员，也不隐式删除家庭。
- 原账号导出白名单包括本人资料、第三方账号关联、会话到期时间与家庭关系，不导出密码、refresh/access/id token 或 sessionToken。
- 已核实第三方头像只清除本地资料引用，不操作第三方对象；未知、自有存储或私有附件头像需先核实生命周期，不能宣称删除完成。历史 VerificationToken 没有 User 外键且无当前写入代码，非空时停止等待归属核实，不能整表清空。
- 微信再次注册可以是空白新身份，不自动继承旧家庭；若要重新参加照护，须由仍有权限的照护者重新邀请。已注销原账号不能自行恢复旧授权。
- 原库失败时作业留在重试状态，sidecar 及旧账号标识保持冻结；成功后才报告完成。恢复时重新执行原账号删除，不能仅相信备份中的 completed 标志。

- 家庭创建的远端写入和本地映射提交保持串行；响应丢失时按稳定 ID 和预期用户名只读核实已创建账号，再纳入确认与清单。归属冲突或尚不能确定远端结果时停止注销，不猜测空账号，也不创建数据来完成删除。

## 验证边界

真实 SQLite 测试验证新旧身份、绑定、原库失败、源数据恢复后的登录拦截与删除重放。隔离 PostgreSQL 测试脚本覆盖部分删除回滚、重复调用、最后照护者离开后的家庭保留、其他用户及混合锁不变。实际原库切换与真机注销须另行验收。

只读源库头像分类：空 5、Google 2、GitHub 1，无已发现的自有 Blob；VerificationToken 为 0。部署仍须重新盘点并配置精确第三方头像来源，不能把本次统计当作永久事实。
