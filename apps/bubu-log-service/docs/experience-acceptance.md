# 0.2.0 体验验收与微信后台材料

当前 0.2.0 已上传，用户确认已设为体验版，服务端已切换。完整部署证据见 [验收记录](validation/experience-020-2026-10-24.md)。

## 手机验收

1. 打开体验版，确认标题为“卜卜日记”，首页保留日历和可视化，历史、设置及隐私入口收在左上角菜单，聊天入口在右下角。
2. 微信登录，分别检查拒绝与同意隐私选项；完成监护人授权后查看原卜卜历史日期、统计和仍存在的照片。最早档案原头像已在源站失效，空头像是已记录的历史问题。
3. 对话输入“喝奶了”，检查助手追问类型、时间及奶量/时长等缺项；补齐后检查保存回执和对应日历变化。准备量与喝掉量应区分，不能把未回答的数据猜成事实。
4. 主动选图上传，检查图片授权、加载和反馈；撤回图片授权后再次上传应被阻止。助手不能仅凭大便照片给出疾病诊断。
5. 打开菜单里的隐私页面，查看政策、导出、反馈和撤回入口。正式家庭先只验导出；注销、家庭删除请另建测试家庭验证，确认删除后旧会话和图片访问失效。
6. 群采集仅处理已开通且授权的群，仍需对应电脑采集执行器在线；它不回复家庭群。信息不完整时应进入程序内待补，完成补问后再形成完整事实。

- 主体资格、服务类目、备案及适用的 AI 服务材料按后台实际要求提交；不能沿用 Hello Agent 的审批结果冒充本产品已审批。
- 手机完成上面的验收，确认合法域名、选图权限和微信登录在真机均可用后，再提交正式审核。
- 运营按已确认方式查看后台和服务器日志；图片误判、隐私请求和未完成删除有人工处理安排。没有配置外部通知，不承诺实时监护。
