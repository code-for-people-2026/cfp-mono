# 卜卜日记身份、照护授权与录入

卜卜日记的身份与授权决定谁能访问哪个宝宝；录入把照护者报告的事情整理为可查询、可补充、可更正的照护记录。群发送者不代表访问身份，服务权益单独管理。

## Language

**照护身份**：可以登录卜卜日记并接受宝宝授权的人；微信身份经本人验证后可关联原宝宝日记账号。

**宝宝授权**：某位照护身份对一个宝宝的查看、记录或管理资格。加入微信群不会自动获得宝宝授权。

**服务权益**：一个宝宝共享的内置聊天与群采集可用状态，在宝宝授权之后另行检查。历史记录及图片的查看资格仍由宝宝授权决定。

**免费服务配置**：运营明确设置的起止时间、独立到期策略与人工暂停状态。未配置截止时间或到期策略不会自动停服；恢复人工暂停不会清除原日期和到期策略。

**权益变更**：带版本、请求号、操作者与理由的一次配置、延长、暂停或恢复。服务按当前时间计算可用性，客户端不自行判断期限。配置与变更共用现有持久层，见 [ADR-0005](docs/adr/0005-baby-service-entitlements.md)。

**宝宝管理者**：有权邀请和移除照护者的人。原账号中的爸爸、妈妈、阿姨等称谓本身不代表管理资格。

**照护邀请**：宝宝管理者授予接收者指定照护范围的一次性凭证；撤权会同时作废该宝宝尚未接受的邀请。

**内置 Agent**：受当前照护者委托处理当前宝宝记录的执行身份，审计保留委托者与 Agent 两种身份。

**采集 Agent**：仅可处理已绑定宝宝和指定群的运行身份。群消息发送者是来源信息，不是采集 Agent 的登录身份。

**运营操作者**：在明确宝宝范围内管理授权和群绑定的受信任工作人员。运营身份不能通过普通登录或聊天声明获得。

运营操作者使用独立 Payload 账号。管理员管理运营账号；运营处理其范围内的宝宝；审计只读角色查看范围内的运行摘要，不读取原消息、完整事实或图片。账号角色及范围每次重新检查，管理员也没有默认的全部宝宝权限。后台只保存命令回执；照护事实、来源、修订、待补和采集进度仍由原模块保存。原生后台与业务服务共享进程和事务队列，见 [ADR-0004](docs/adr/0004-native-operations-with-shared-runtime.md)。

**照护事件**：宝宝实际发生的一件照护活动，可以尚未结束或缺少部分信息。同一事情的补充与纠错沿用原事件。

**待补充事项**：围绕某件照护事件尚需确认的字段、矛盾或重复疑问；明确不知道与尚未发生分别保留，不被视为零或否。

**候选记录**：已保存来源与整理结果，但因类型、发生时间或矛盾尚未解决而未计入事实统计的事件。

**来源**：报告一件事的原消息、发送者和消息时间。同一事件可以有多个来源，消息中的称谓不授予宝宝权限。

**疑似重复**：来自不同入口、可能描述同一件事的记录；核对前不新增统计次数。确认相同后合并来源，确认不同才分别计入。

**撤销记录**：照护者明确删除或撤回的误记，其来源与修订仍保留；重放原消息不会使它重新出现。

**统计覆盖**：已记录事情中，哪些数量与时长已知、未知、仍在进行或待核对的说明。已知零是一条事实，未知不折算成零。

**私人对话**：某位照护身份围绕当前宝宝的持续交流；聊天文本按身份及宝宝隔离，同宝宝其他照护者只共享有权访问的照护事实和待补事项。

**对话轮次**：一次有稳定请求号的输入、工具执行检查点和回复。轮次完成不代表记录已完整；保存状态以统一 MCP 回执为准，失败或重启沿用原请求恢复。

**采集批次**：对一个已绑定群的一段增量消息所做的整理工作；每条消息有保存结果或明确的忽略理由后才推进进度。

内置对话使用独立 `chat-turns` 集合，并通过同一 `openStore` 注册和生产迁移维护。Agent 的结构化工具调用通过真实 MCP；15 类规则、统计、来源与持久待补不在聊天再实现。客户端浏览日期只提供上下文，当前输入时间与群消息时间分别保留。决策见 [ADR-0003](docs/adr/0003-private-chat-and-mcp-execution.md)，接入见 [对话接口](docs/chat.md)。

**隐私选择**：照护者本人授权与宝宝监护声明，按政策版本、目的与图片/AI/群采集独立保存，不替代身份权限。**隐私删除**：监护人确认的家庭硬删除或本人账号注销；冻结、持久删除清单、重试和备份重放共同防止数据复活，与可撤销的照护事件删除区分。**安全提示**：明确危险描述触发的固定提示及最小运营核对事项，不构成诊断或实时监护。见 [ADR-0006](docs/adr/0006-privacy-and-data-lifecycle.md) 和 [上线准备](docs/launch-readiness.md)。

**私有原数据层**：原 Payload 照护表在境内的单一权威实例；与 sidecar 共享授权边界但不合并数据库。物理迁移与家庭生命周期见 [ADR-0007](docs/adr/0007-private-original-payload.md)，代码在 `apps/bubu-log-core`。

- 已绑定账号注销、稳定原账号冻结及本人资料导出见 [ADR 0008](docs/adr/0008-linked-account-erasure.md)。共享家庭记录不能随最后一位照护者注销而自动删除。
- 运行监测、原数据库与 sidecar 的停写备份，以及不覆盖生产的隔离恢复见 [ADR 0009](docs/adr/0009-operations-and-backup-boundaries.md)。全局状态不扩张管理员的家庭访问范围，备份成功不等于恢复演练或外部通知已验收。
