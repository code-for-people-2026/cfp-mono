# 哺哺日记身份与照护授权

哺哺日记的身份与授权决定谁能访问哪个宝宝。照护事实、聊天材料、群发送者和服务权益分别属于后续模块。

## Language

**照护身份**：可以登录哺哺日记并接受宝宝授权的人；微信身份经本人验证后可关联原宝宝日记账号。

**宝宝授权**：某位照护身份对一个宝宝的查看、记录或管理资格。加入微信群不会自动获得宝宝授权。

**宝宝管理者**：有权邀请和移除照护者的人。原账号中的爸爸、妈妈、阿姨等称谓本身不代表管理资格。

**照护邀请**：宝宝管理者授予接收者指定照护范围的一次性凭证；撤权会同时作废该宝宝尚未接受的邀请。

**内置 Agent**：受当前照护者委托处理当前宝宝记录的执行身份，审计保留委托者与 Agent 两种身份。

**采集 Agent**：仅可处理已绑定宝宝和指定群的运行身份。群消息发送者是来源信息，不是采集 Agent 的登录身份。

**运营操作者**：在明确宝宝范围内管理授权和群绑定的受信任工作人员。运营身份不能通过普通登录或聊天声明获得。
