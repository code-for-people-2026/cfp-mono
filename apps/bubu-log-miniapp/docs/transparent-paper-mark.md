# Transparent paper-back mark

`src/assets/branding/bubu-mark-transparent-v1.png` is a separate transparent wallpaper asset. The existing menu/app icon remains `bubu-avatar-borderless-v1.png`.

Created with the built-in image generation/editing tool from the original logo. No photo upload or server image processing was introduced. The PNG retains the brown mark, peach accent, ivory eye and transparent margins; it is repeated in 50vw square cells over one continuous paper background.

Edit prompt:

> Edit this exact existing Bubu logo asset for transparent wallpaper tiles. Remove ALL cream/peach gradient background to true alpha transparency, including the tiny circular hole inside the brown head. Preserve the original dark brown stylized baby/Chinese 卜 mark silhouette, exact proportions, rounded strokes, brown color and peach curved accent stroke. No redesign, no added shapes, no border, no shadow, no colored square backing, no checkerboard baked into pixels. Keep same centered size and generous original square transparent margins so it can tile at 50vw without seams. Output a square transparent PNG, suitable as app asset.

The first result lost the eye, so the final asset uses this corrective prompt with the first cutout and original logo as references:

> Target image1 is the transparent logo cutout. It accidentally LOST THE SMALL ROUND CREAM-WHITE EYE from original image2. Restore exactly that little solid round ivory eye, centered approx x50.5% y31.6% of full canvas, diameter3.2% of canvas. Image2 is reference only for exact original eye position, shape, color. Preserve image1 EVERYTHING ELSE pixel appearance: same brown and peach symbol, same size/proportions/position, same truly transparent background outside mark, square canvas with original margins. Do not fill background, no cream rectangle, no shadow, no new design. Only restore the missing cream-white eye dot.
