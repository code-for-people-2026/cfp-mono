# 可视化组件

这些组件只接受读取到的 Activity 和 DailyStat，点击活动调用页面传入的详情回调，不创建或修改记录。所有视图使用 Taro View / Text / ScrollView / Image；趋势线是 View 线段，使用 Taro 的选择器测量绘图区域，不依赖 DOM、SVG 或 Web 图表库。

趋势图的尺寸测量是异步的。数据先到但尺寸尚未返回时显示绘图准备态，避免把空网格当作已绘完的图；原生视图首次布局返回空尺寸时有最多 3 次有界重试，失败后支持重试。E2E 必须等待可见的 `.bubu-chart-line`，只等待页面提示或数值不能证明折线已绘制。

- `DayTimeline`：24 小时时间轴，使用 model 裁剪跨日活动，保留活动间隔。`latestActivities` 可提供跨当天边界的最近喂奶与睡眠，刷新“距上次”显示；省略时使用 `activities`。
- `WeekCalendar`：7 列周历和原有四组分类开关，点击活动查看详情，点击日期打开当天记录。
- `TrendCharts`：7 / 14 / 30 天的睡眠、瓶喂及吸奶、尿布三组图。睡眠绘图时将原始分钟除以 60 转为小时，选中日期的明细保留小时和分钟，不修改 DailyStat。点击图表日期列可查看数值。
- `Heatmap`：近 4 周睡眠 / 奶量切换，点击格子查看数值，“查看当天”调用 `onDateClick(date, metric)`，页面据此恢复对应分类筛选。
- `ActivityDetail`：只读底部面板，照片调用 `Taro.previewImage`，加载或预览失败会显示反馈。

## 缺统计的显示

模型保持旧服务端 DailyStat 口径，不从 Activity 重算日统计。旧网页趋势对缺少 DailyStat 的日期补了数值 0，同时标记 `hasData: false`；此处保留模型补位，但绘图时仅连接相邻 `hasData: true` 的日期。缺失的日期显示断线和“暂无统计”，热图显示虚线格，避免把“尚未生成日统计”呈现为“实际睡眠或奶量为零”。真实存在的 DailyStat 值为 0 时仍绘制零点。这是明确的呈现差异，不改变数据、汇总公式或日期归属。
