# 可视化组件

这些组件只接受读取到的 Activity 和 DailyStat，点击活动调用页面传入的详情回调，不创建或修改记录。所有视图使用 Taro View / Text / ScrollView / Image；趋势线是 View 线段，使用 Taro 的选择器测量绘图区域，不依赖 DOM、SVG 或 Web 图表库。

趋势图的尺寸测量是异步的。数据先到但尺寸尚未返回时显示绘图准备态，避免把空网格当作已绘完的图；原生视图首次布局返回空尺寸时有最多 3 次有界重试，失败后支持重试。E2E 必须等待可见的 `.bubu-chart-line`，只等待页面提示或数值不能证明折线已绘制。

## 语义调色板

HOME 各视图共用 `src/model/presentation.ts` 的 `ACTIVITY_CATEGORY_TONES`，不在日历、摘要、月环或图表里各自复制类别色。前景/环色用于文字、点、环和折线；浅底色只作事件背景；边框色用于描边。四个月环指标顺序保持“睡 → 玩 → 吃 → 便”。

| 类别 | 前景/环 | 浅底 | 边框 |
| --- | --- | --- | --- |
| 睡眠 | `#6f5688` | `#f0ebf6` | `#b4a0ca` |
| 户外 | `#8c651f` | `#fbf2d9` | `#d9b85f` |
| 亲喂/瓶喂（奶量） | `#a34f70` | `#fbe9ef` | `#d991ab` |
| 换尿布（不分大小便） | `#806b17` | `#f9f3d5` | `#cbb755` |
| 吸奶 | `#80566d` | `#f5e8f0` | `#c493ac` |

`activityTone`、摘要卡、周历筛选、月环/明细、趋势图和“距上次”圆点都从这一份调色板取色。吸奶与瓶喂在趋势图中分别成系列并保留标签。其它未列出的活动保留既有通用色调，尤其是共用黄色/琥珀色的洗澡、抬头等活动，不为尿布或户外改掉旧值。

- `DayTimeline`：24 小时时间轴，使用 model 裁剪跨日活动，保留活动间隔。睡眠与户外记录在完整日画布上从左缘铺到右缘（包含小时标签列），文案与前景记录层左缘对齐，不参与前景重叠分栏；每条记录仍可点击。`latestActivities` 可提供跨当天边界的最近喂奶与睡眠，刷新“距上次”显示；省略时使用 `activities`。
- `WeekCalendar`：7 列周历和原有四组分类开关，点击活动查看详情，点击日期打开当天记录。睡眠与户外记录同样铺满当天列作为背景；前景重叠事件按只针对前景的分栏布局。事件块使用紧凑的测量值标签（`120ml`、`7h`、`10m`、`3次`），没有测量值时才回退到短类型名（`瓶喂`、`睡眠`、`大小便`）；完整活动名称和时间范围放在 `aria-label`，点按仍打开完整只读详情。窄赛道把数字和单位分成两行，并给测量值稍宽的赛道；最小可读高度（两行）由当前画布高度换算成百分比后传给 model，与分栏碰撞使用同一高度。三重以上重叠仍受物理宽度限制，文本类型可以截断，但数值与单位不拼接、不篡改，标签不溢出到相邻日期列；背景带和点按行为不变。最小可读高度不再只靠 CSS `min-height`。
- 日／周时间轴共享 `src/gestures` 的顺序状态机与 React/ScrollView 适配器，不复制两套 touch handler。页面持有共享 scale，日／周切换保留。

## 时间轴手势

- 单指左滑看前一段、右滑看后一段；日前进一天，周前进一周。方向按用户明确要求，不改成常规 pager。
- 仅在顶部 00:00 向下或底部 24:00 向上、从边界起手并向外拉动超过 72 物理像素后，最终松手才翻页。普通中间滚动不翻页；从边界向内拖回仍是普通滚动；仅靠惯性到达边界不触发。低于阈值回退会取消，`touchcancel`、菜单／详情／日期／宝宝切换、多指和卸载都会取消。
- 双指上下捏合在 0.5–3× 间连续缩放，用两指垂直间距计算，并以两指中点锚定时间；两指同向移动不缩放。单指纵向滚动仍由原生 ScrollView 处理。
- 拖拽、捏合、取消后会抑制随后的合成 click；普通点按仍会打开记录。手势只在时间轴视口内生效，日期栏、菜单、详情和筛选区不安装监听。
- H5 在时间轴元素上安装元素级 touch 监听，使用 `touch-action: pan-y` 和非被动 `preventDefault` 阻止浏览器缩放；原生把触摸交给画布，捏合时通过 `catchMove` 与 enhanced ScrollView 的 `scrollEnabled` 暂停用户滚动，并以 `animated: false` 的程序化偏移锚定，不逐帧动画。
- 相对标题由 `useToday` 在页面回前台、H5 可见性恢复和上海午夜刷新，只更新时间上限，不重置用户浏览日期。
- `TrendCharts`：7 / 14 / 30 天的睡眠、瓶喂及吸奶、尿布三组图。睡眠绘图时将原始分钟除以 60 转为小时，选中日期的明细保留小时和分钟，不修改 DailyStat。点击图表日期列可查看数值。
- `Heatmap`：自然月四层照护环，外到内为睡（睡眠时长）、玩（户外时长）、吃（瓶喂奶量+亲喂估计/记录量）、便（尿布数量），复用 `ActivityRings` 的纯 View 渲染。展示顺序和固定颜色均按指标 key 查找，不依赖模型元组位置。日期在环上方，选中日一次列出四项原始数值 / 区间和本地参考；参考来自宝宝年龄或家庭设置，只约束画环比例，不替换文字数值，也不按状态变色。亲喂奶量只显示记录量或明确标注的本地速率估算。缺失环为虚线，真实记录零不补造数值。前后月补格与未来日期不暴露照护数据。“查看当天”调用 `openDay(date)` 进入未筛选的日视图，可返回原月。
- `ActivityDetail`：只读底部面板，核心照护字段在前；创建/更新元数据移入默认折叠的「更多信息」，仅在首次展开时由页面发起审计读取。来源显示记录账号 ID、文本/语音方式、添加时间与原话；缺失值不猜测。不可用或读取不完整时使用稳定的普通文案和重试，不展示服务端错误正文。长账号和原话在 320px 下换行并留在滚动面板内。照片调用 `Taro.previewImage`，加载或预览失败会显示反馈；关闭、切换活动/宝宝/会话后重新从折叠状态开始。

## 缺统计的显示

模型保持旧服务端 DailyStat 口径，组件只读展示，不从 Activity 重算日统计。趋势图只连接相邻 `hasData: true` 的日期；月历环同时传入已保存 DailyStat 和完整月 Activity 读取结果，睡眠、瓶喂和尿布文字优先展示已保存口径，户外与亲喂来源由 Activity 展示模型说明。缺失环显示虚线，避免把“尚未生成日统计”呈现为“实际为零”。真实存在的 DailyStat 值为 0 时仍按记录零展示。这是明确的呈现差异，不改变数据、汇总公式或日期归属。
