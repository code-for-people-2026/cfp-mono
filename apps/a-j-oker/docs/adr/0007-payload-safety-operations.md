# 运营处置与原始记录分离，归同一 Payload 事实来源

审核案件、最小证据、处置状态与追加审计保存在现有 Payload；处置通过领域读取投影和写入守卫生效，不通过改写原始聊天模拟删除或复核。案件变更、处置执行与审计在同一数据库事务提交，代价是需要维护所有业务读取和生成入口的隔离规则；应用层只追加审计不等于数据库管理员无法改写，外部存证仍是独立缺口。

2026-10-16：运营界面收回 Payload 原生资源列表与详情。列表复用原生权限、筛选和分页，详情通过 UI 字段提供受控操作；追加版本的表单置于对应资源列表。移除独立 `/operations` 页面，保留原有运营服务、认证接口及事务审计边界。通用资源写权限不为界面便利而开放。
