# ADR-0011：专家直接接管一个持久任务

状态：本地实现与微信开发者工具联调完成，2026-11-15。未部署远端、上传小程序或进行手机真机验收。

本决策对应 `aj-v5.5` 提示词版本。代码回归之外，已在本机开发者工具使用隔离测试身份调用配置中的实际模型；有限联调案例不代表供应商模型的全面行为评测。

## 决策

阿 J 的协调者仍选择启用的心理专家，但专家通过既有标准 A2A 执行路径提交自己的用户可见回复、受限回应作品、生命周期和实际引用。宿主在原生成轮次内执行同一套所有权、内容审核和 `complete()` 保存门禁；协调者不再改写成功交接后的回复，也不在同轮追问专家。

每个已提交轮次保存服务端生成的专家任务快照。会话锁内从最后一个已完成的专家转换推导当前专家；失败轮次不清除活动任务，明确完成、不可用、隐私忘记或带活动 taskId 的「回到阿 J」动作结束任务。后续普通文字和已验证表单直接发送给同一专家，不创建另一个顶层协调模型。客户端提供的 agent、来源或任务身份均不作为可信依据。

快照固定专家名称、方法、配置修订、私有提示词绑定、当前任务、主题、布局和组件允许范围。公共投影删除私有提示词、任务摘要和组件策略，只展示注册名称、方法、状态、主题，以及经过 `usedSourceIds` 和正文读取状态共同验证的来源。历史卡因此不随后台配置改名或换色。

CMS 只接受 `sage`、`blue`、`plum`、`amber` 主题和有限布局/组件枚举。每个方法拥有自己的主题、布局、允许作品和首选作品默认值，不按列表位置轮换。允许作品留空明确表示禁止作品；首选作品留空明确表示优先纯文字，不会在加载时恢复成表单。首选作品必须是允许作品的子集。seed 仍只补缺，不覆盖管理员已有提示词、启停状态、知识绑定或展示选择。

部署迁移把功能上线前的既有专家按方法键补成上述默认展示，同时保留原记录、提示词、知识绑定和问候；新字段保持可空，以便方法级加载回退。迁移上线后的明确后台选择（包括空数组）不由 seed 或加载器覆盖。
由于回退会删除持久专家快照和管理员展示选择，`down` 明确拒绝自动执行；需要回退时必须先备份并制定数据转换方案。

## 本次验证边界

已用隔离临时 SQLite 库实际执行专家功能前的迁移链，写入旧专家配置、定制提示词、知识绑定和问候，再执行部署迁移并通过 Payload 读取；同时核对生成 schema 的列名、可空性和索引形状，以及外键和完整性。该迁移检查仅使用临时数据库。随后本机联调使用独立测试身份和本机开发数据库，临时绑定明确标注的测试知识资料；测试后恢复专家配置并停用该测试资料，不改变年龄核验规则或真实用户身份。

通用协议增加不含心理业务词汇的 origin/theme/state/source 描述，通用 Taro UI 提供 origin header seam；阿 J 将自己的专家快照映射到该展示概念。提交后的问答固定为问题在上、答案在下的全宽纵向布局。专家表单被更新表单替代或任务结束时，客户端显示失效原因并禁止提交；服务端仍独立核对来源、任务、是否已提交及是否已被替代。

## 本机联调记录（2026-11-15）

微信开发者工具连接 `http://127.0.0.1:3310`，使用隔离测试身份和虚构案例。认知行为专家（蓝色、编号布局）与接纳承诺专家（紫色、纵向布局）均直接接管并承接表单答案；ADK 持久事件确认初次交接经过协调者，而后续文字和表单轮次只执行当前专家。返回后普通对话重新由协调者回复。

实测覆盖：单份内嵌表单填写提交、问题在上答案在下的收起摘要、长选项换行、只要求一道单选题时无补充字段、只要求一道开放式表单题时无额外字段、刷新恢复、实际资料与无资料标记、替代表单及结束任务后的禁用状态。单题约束只影响当前明确请求，不会强制后续专家交互全部单选或单题。实际来源使用明确标注的非正式测试资料；恢复配置后，历史来源仍作为该轮快照保留。

知识来源测试中出现一次模型执行失败，界面保留填写内容与活动专家任务；手动重试成功并收起摘要。这个结果验证失败恢复，不代表模型调用不会失败。

独立复跑服务端 511 项、miniapp 263 项、共享 UI 35 项、协议 16 项及 AJ 展示契约 19 项测试；类型检查、临时数据库生命周期及迁移检查、微信/H5 构建和 5 个原生 WXSS 文件检查通过。年龄核验规则、真实用户身份、远端环境及微信发布状态均未变更。

## 与既有决策的关系

本决策修订 ADR-0004 和 ADR-0010 中“专家只给方案、主助手整合”的部分；保留 ADR-0001 的 Payload 所有权、ADR-0005 的配置/知识权限、标准 A2A 任务与幂等账本、内容审核、危机分流、年龄及隐私门禁。它不开放外部 Agent、BYOK 或公网专家端点。
