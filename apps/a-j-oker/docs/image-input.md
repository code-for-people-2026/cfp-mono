# 图片输入与识图

聊天上传使用 `HELLO_IMAGE_REVIEW_MODE=aliyun-green` 与服务端私密的
`HELLO_GREEN_ACCESS_KEY_ID`、`HELLO_GREEN_ACCESS_KEY_SECRET`。凭证不进入小程序或 H5。
仅声明旧的 `HELLO_IMAGE_REVIEW_URL` 不能开启实际上传。

图片先限制体积并标准化为 JPEG，再经阿里云内容安全增强版上海节点的
`baselineCheck` 审核。审核只接受明确的 `none` 风险结果；拒绝、未知结果或服务不可用时，
不写入应用的私有 OSS。审核使用 Green 自有临时存储，不公开用户图片的读取地址。
通过后遵循 ADR-0002，由服务端核对归属后读取，再作为图片输入传给模型。

配置会将阿里云审核接收方加入隐私说明、改变政策版本，现有用户必须主动重新同意。
上传还要求敏感信息处理授权。平台与自带密钥使用支持视觉输入的 DeepSeek 模型；
外部连接提供已授权图片的读取能力，能否理解图片取决于所连接的客户端及模型。
本次只开放图片输入，不包含 AI 生图。

在已构建的服务镜像中运行 `pnpm exec tsx scripts/image-input-smoke.ts`，可用真实审核、
私有 OSS 和 DeepSeek 验证上传、图片归属、平台/BYOK 识图、历史、导出与删除。
脚本只创建隔离的临时数据库和合成测试身份，不修改用户年龄、同意或聊天数据。
测试结束时清理上传的测试图片。须同时提供现有的存储、模型、审核和隐私运营配置。
