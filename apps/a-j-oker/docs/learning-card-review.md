# 休息提醒卡与本地人工评阅

2026-10-31 负责人变更首版范围：通用海报、计算题、计算卡等制作直接拒绝，仅保留明确的休息提醒卡。旧版11条计算卡生图结果作为历史证据保留；新版本的正确行为是拒绝且不调用生图，不将历史图片改写为通过。原始请求安全拒绝仍优先，不生成替代图。

另外收窄自助删除指引识别：仅在明确询问删除个人资料或确认是否已删除时介入，不能把“重新发布已删除用户数据”等请求直接路由到删除指引。识别版本为 aj-interaction-v7。

## 本地评阅服务

`node scripts/manual-review-server.mjs /absolute/path/config.json` 启动独立服务，不连接产品数据库或模型。配置包含 `site`（已生成的评阅静态页）、`storage`（与静态目录分离）、至少 24 位随机 `token`、`hosts`、`port`，默认仅绑定 127.0.0.1。家庭网络可明确设置 `bind: "0.0.0.0"` 和具体私网地址；服务拒绝非私网来源和非允许 Host，不做公网隧道。

存储目录由操作者提供 `manifest.json`（`[{id,hash}]`）及 `seed.json`（已确认、指纹匹配的历史评阅）。`GET /<token>/api/state` 返回当前输出对应的记录和版本；同源页面以 `POST api/save` 提交 `{record,revision}`。每次成功回执前，将记录追加到 `history.jsonl` 并 fsync；重启从历史重放。旧输出记录仍保留，但不套给新输出。版本冲突返回 409，不覆盖另一个页面的判断。只有静态页、指定报告及按哈希命名的图片可读取，记录文件和配置不可通过静态路由获取。

页面应在服务器确认前显示正在保存，失败保留浏览器暂存并重试；存在未保存内容时阻止静默关闭。本地记录为人工结论，测试只能使用独立合成样本，不能代评真实题目。

验证：`node --test scripts/manual-review-server.test.mjs` 覆盖落盘、重启恢复、并发覆盖保护、错误输出指纹、跨源请求及私有文件不可读取。
