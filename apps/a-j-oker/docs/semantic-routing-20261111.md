# 语义路由与图片意图回归

普通倾诉中的词语可能分别描述不同对象，例如虚构最小案例：

> 有人提醒我交稿，但我不想加班，心里很烦。

这不是修改产品提醒设置的请求。输入审核现在基于当前完整输入和有界会话上下文返回服务范围及七个严格布尔字段：minor、crisis、dependency、overuse、exit、forget_context、image_requested。引用、历史、否定和第三人称内容必须与当前用户的实际意图区分。

## 行为

- 移除产品帮助、互动意图、遗忘上下文和图片范围的自然语言关键词路由。普通倾诉进入生成器，产品帮助由产品知识和模型回答。
- 图片工具仅对已通过语义准入的本轮图片请求或有效恢复流程开放。原始请求在提交、恢复和作品保存时再次校验；像素审核、归属、额度和幂等规则保留。
- 审核返回无效、字段缺失或服务不可用时停止本次请求，不回退到关键词猜测。这意味着依赖语义判断的安全流程也受审核服务可用性影响。
- 连续使用两小时提醒仍由服务端时间累计；语义上的长时间聊天意图不伪称实际已使用两小时。
- 模型审核使用温度 0 和 JSON 对象格式；完整当前输入单独传递，历史摘要与近期对话有长度边界。历史关键词计数仅保留作审计数据，不传给审核模型作判断提示。

## 回归与验证边界

`semantic-keyword-history.json` 保存 50 条历史正则、682 个关键词或字面组成项，以及 284 个回归案例。原规则的提交、路径、行号和出现记录保存在每条记录中。案例覆盖普通倾诉、引用、否定、历史年龄、第三方情境、危机、退出、遗忘、图片准入与拒绝；11 项直接覆盖图片审核目的。

所有入库测试文本均为虚构案例。原始问题叙述、模型请求/回复报告以及服务器部署回执不随代码发布。

```sh
pnpm --filter @cfp/a-j-oker typecheck
pnpm --filter @cfp/a-j-oker test
pnpm --filter @cfp/a-j-oker test:interaction
pnpm --filter @cfp/a-j-oker test:images
pnpm --filter @cfp/a-j-oker test:forget-context
pnpm --filter @cfp/a-j-oker test:integration
pnpm --filter @cfp/a-j-oker lint
```

`test:interaction` 包含历史覆盖清单检查，并由现有 CI 执行。普通测试使用明确的合成审核结果/供应商，不访问真实模型、图片供应商、联系人或生产数据库。

2026-11-11 的历史真实模型评估曾完成 284 项语义判断与 10 项完整对话。隐私修订替换了其中部分输入，旧原文报告已删减，因此这些历史通过数不代表当前全部案例已经重新实测。修订后的虚构最小案例已使用 deepseek-flash 重新跑完整输入审核、生成和输出审核，正常完成，没有被设置提示截走或生成未请求图片。

显式真实模型复测入口为 `scripts/semantic-history-live.ts --live` 与 `scripts/semantic-conversation-live.ts --live`；需要单独配置模型凭据。两者不属于默认 CI；完整对话入口使用独立的合成账号和临时 SQLite，报告应留在本地，不提交原始输入或模型回复。
