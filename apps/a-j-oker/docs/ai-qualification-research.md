# 阿 J 小程序 AI 类目与备案路径核查

核查日期：2026-09-30。范围：中国大陆面向公众的小程序；项目使用第三方 DeepSeek API，不自行训练模型。产品领域背景见 [CONTEXT.md](../CONTEXT.md)。本文仅记录公开官方材料及本轮用户截图，不代表主管部门已判定本项目的适用路径；未提交申请、签署协议或修改代码。

## 当前可以判断的事

- 用户截图选择了微信「深度合成 > AI 问答」的自研路径。按本项目使用第三方 API 的事实，应核对「使用第三方技术」路径：技术主体的生成合成类算法备案材料，以及小程序主体与技术主体的合作协议。截图要求协议体现算法名称、应用场景或备案编号，并有双方鲜章。腾讯云开发官方文档也明确区分自研和第三方材料；其“无需鲜章”说明仅限微信云开发资质，不能推及 DeepSeek 或其他供应商。[腾讯云开发官方指引](https://docs.cloudbase.net/en/ai/release/algorithm-filing)
- 因此，不能只因小程序自身没有“自研算法备案”就判断没有可申请路径。眼前的关键是小程序主体是否满足类目门槛、能否取得实际技术供应商对应的材料，以及主管部门要求的应用登记/备案是否完成。[腾讯云开发官方指引](https://docs.cloudbase.net/en/ai/release/algorithm-filing)、[国家网信办最新公告](https://www.cac.gov.cn/2026-09/14/c_1791136833136332.htm)

## 三个名称必须分开

| 项目 | 官方口径与对象 | 对本项目的含义 |
| --- | --- | --- |
| 生成式人工智能服务备案，常被称作“大模型备案” | 国家网信办公告单列在国家网信办完成备案的生成式人工智能服务。 | 不因开发了小程序，就把自己当成自行提供底层模型的主体；按实际模型提供、训练和部署方式判断。 |
| 生成式人工智能应用/功能登记 | 2026-09-14 国家网信办公告明确：通过 API 等方式直接调用已备案模型能力的应用或功能，由地方网信办开展登记。 | 本项目应优先核对这条属地路径。已上线应用还应公示所用服务、模型名称、备案号或上线编号。 |
| 互联网信息服务算法备案，含深度合成服务算法备案 | 《算法推荐管理规定》第 24 条规定具有舆论属性或社会动员能力的算法服务提供者的备案；《深度合成管理规定》第 19 条另规定相关服务提供者、技术支持者的备案要求。 | 微信第三方类目材料使用技术主体的算法备案，并不自动解决应用运营者在法规下是否另负备案义务。 |

来源：[国家网信办 2026 年 7—8 月公告](https://www.cac.gov.cn/2026-09/14/c_1791136833136332.htm)、[《互联网信息服务算法推荐管理规定》第 24—27 条](https://www.cac.gov.cn/2022-01/04/c_1642894606364259.htm)、[《互联网信息服务深度合成管理规定》第 19—20 条](https://www.cac.gov.cn/2022-12/11/c_1672221949354811.htm)。

《生成式人工智能服务管理暂行办法》第 2 条以向境内公众提供生成内容的服务为适用范围；未向境内公众提供服务的研发应用另有排除。第 17 条对具有舆论属性或社会动员能力的服务要求安全评估及算法备案；第 22 条的提供者定义包含组织和个人。因此，不能断言所有 API 应用都只要登记，也不能断言所有 API 应用一律要“三项全办”；不能把微信的非个人主体门槛直接解释成国家法规排除个人。[《生成式人工智能服务管理暂行办法》](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)

## 属地受理、难度与时间

全国公告明确通过属地网信部门办理。具体材料、是否测评、受理方式和个人主体的可操作入口，要向运营主体所在地网信部门核对；本次没有获得用户主体所在地，不能指定某省规则适用。[国家网信办公告](https://www.cac.gov.cn/2026-09/14/c_1791136833136332.htm)

福建省网信办公开办事问答提供了一个地方例子：省级登记由企业获取材料、向市级提交盖章材料初审，再由省级复审、组织安全评估及相关部门意见，通过后发放登记号；中央备案则有向中央报送的后续环节。这说明“登记”也可能需要实质材料及测评，不能理解为填表即过。该例仅说明存在地方办理细节，不能套为全国统一清单。[福建省生成式人工智能大模型备案服务专区](https://www.fjwx.gov.cn/beian/)

明确查到的全国法定期限是**算法备案材料齐全后 30 个工作日内予以备案**；材料不齐全，也应在 30 个工作日内通知并说明理由。第 24 条另有提供服务后 10 个工作日内履行算法备案的提交期限；它不是整套生成式 AI 应用可先上线的通行许可。[《互联网信息服务算法推荐管理规定》第 24—25 条](https://www.cac.gov.cn/2022-01/04/c_1642894606364259.htm)

本次未查得适用于全国的“应用登记必定几天办完”承诺，也未查得本项目适用的统一价格。以上 30 个工作日不能套用于应用登记、供应商签约、材料准备、测评补正和微信审核总时长。可以判断第三方 API 路径有现成制度入口；能否省力，首先取决于主体条件和供应商材料是否满足要求，不能承诺包过或统一周数。

## 本产品新增的适用边界，待核对

2026-07-15 起施行的《人工智能拟人化互动服务管理暂行办法》第 2 条针对模拟自然人人格、思维和沟通风格的持续情感互动；不涉及持续情感互动的知识问答、工作助手等不适用。第 22 条规定上线相关服务/功能的安全评估及向省级报送，第 26 条规定算法备案及年度核验。本项目有固定人格、持续会话和情绪回应，需按实际功能与定位核对该边界；仅凭“AI 问答”类目名称不能认定适用或不适用。本轮未开展完整产品法律评估。[正式办法第 2、22、26、32 条](https://www.cac.gov.cn/2026-04/10/c_1777558395078289.htm)

## 尚缺信息与下一步

1. 核对小程序是个人、个体工商户、企业还是组织主体；不要只看 API 账号类型。
2. 若继续直连 DeepSeek，先核对官方协议模板和对应算法材料，确认能够满足微信第三方技术路径；目前尚未取得或签署本项目的协议。
3. 明确运营主体所在省市，再获取属地当前应用登记指南，询问本项目在第三方 API、持续情感互动等具体功能下的登记、算法备案和安全评估适用要求。
4. 各材料的产品名、小程序 AppID、主体、实际供应商和模型应保持对应。微信类目审核通过与网信手续完成需分别核实。

研究范围内未发现能证明“本项目已经没有资质可申请”或“已经满足全部要求”的证据。最实际的判断是：第三方技术路线存在；个人小程序主体是明确的平台门槛；非个人主体仍需补齐对应的供应商合作材料并核对属地手续。
