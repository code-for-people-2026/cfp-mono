# 街坊味

街坊味帮助店铺经营者维护菜品、安排周菜单，并整理发给顾客的菜单文字。当前围绕桃子的店铺，顾客点餐属于后续阶段。

## Language

**店铺**：菜品池、周菜单及历史的共同归属。正式产品当前服务桃子的一个店铺，可由多人共同经营；测试环境为每位测试者准备独立店铺。
_Avoid_：把店铺和微信账号当成同一实体

**经营成员**：经店主授权管理店铺的人员。每位成员使用自己的微信身份，多名成员共同维护同一店铺数据。
_Avoid_：把微信项目成员直接当作经营成员、共用微信账号

**微信身份**：识别登录人的身份，不代表其天然具有店铺管理权限。
_Avoid_：把登录成功等同于获得经营权限

**顾客**：向桃子店铺购买餐食的人。顾客端属于后续阶段，其订单属于本人，不赋予店铺管理权限。
_Avoid_：经营成员、开发者

**测试店**：开发与试用使用的店铺数据，独立于正式经营数据。每位测试者有自己的测试店，各店互不可见；明确加入同店的成员才共同维护数据。
_Avoid_：把独立试用当作同店协作、把测试店当作公开商户入驻
