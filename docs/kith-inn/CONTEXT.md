# Kith Inn 订餐管理上下文

Kith Inn 帮助社区内的家庭做饭者管理菜单、预订、配送和线下收款记录。本词汇表只定义产品领域中的统一用语。

## Language

**餐次**：
某一具体日期的午餐或晚餐，是菜单、每份价格、容量、订单和配送的共同归属对象。
_Avoid_: 场次、班次

**餐次日历**：
按日期组织午餐和晚餐、用于查看近期记录和未来供餐安排的视图。
_Avoid_: 营业日历、菜单日历

**待安排餐次**：
尚未由商家决定是否供餐的餐次；它不代表未来一定会开放预订。
_Avoid_: 未决定餐次、未营业餐次

**不供餐餐次**：
商家已经明确决定不提供服务、且从未开放预订的餐次。
_Avoid_: 已取消餐次、关闭餐次

**开放预订餐次**：
商家已经公开菜单并允许顾客下单的餐次；满单、截止或商家主动停止接单后不再接受新的顾客订单。
_Avoid_: 已发布餐次、营业餐次

**停止接单**：
已开放餐次因为满单、到达截止时间或商家主动操作而不再接受新的顾客订单，已有订单不受影响。
_Avoid_: 取消餐次、关闭餐次

**已取消餐次**：
曾经开放预订、后来由商家决定不再履约的餐次；它与从未开放的“不供餐餐次”不同。
_Avoid_: 不供餐餐次、停止接单

**订单**：
针对一个具体餐次已经确认的份数记录，订餐对象可以是顾客，也可以是桃子自家；P0 中同一订餐对象在同一餐次至多有一笔有效订单，追加需求属于份数调整而不是新订单。
_Avoid_: 长期订单、预订意向、追加订单

**首单申请**：
尚未获得商家确认的用户，针对一个具体餐次提交的首次订餐请求；它不是订单，也不占用餐次容量。
_Avoid_: 待确认订单、未验证订单

**商家邀请**：
商家通过菜单卡片、邀请卡片或小程序码提供的进入凭证，使用户可以访问该商家的内容并提交首单申请；它本身不证明用户身份。
_Avoid_: 平台注册、公开入驻

**顾客关系**：
一个用户账户与一个商家之间的服务关系，决定该用户能否查看该商家的内容并向其下单。
_Avoid_: 全局顾客身份、平台会员

**已确认顾客**：
商家已确认其小程序账户对应自己认识且愿意服务的微信顾客；这不代表平台完成了实名身份认证。
_Avoid_: 实名顾客、认证顾客

**单次代下单**：
桃子根据顾客的线下请求，为其创建或调整一个具体餐次订单的操作。
_Avoid_: 手工单、线下单

**订单创建来源**：
订单首次建立的途径，取值为顾客自助、商家代下、订餐约定或自家；后续由桃子调整份数不改变创建来源。
_Avoid_: 订单类型、最后修改人

**订餐约定**：
桃子维护的未来订餐规则，可以记录顾客私聊达成的约定，也可以记录自家用餐需要；它本身不是订单，匹配到实际开放的餐次并经桃子确认后才生成订单。
_Avoid_: 批量预订、长期订餐、长期订单、订阅订单

**自家订单**：
由桃子的自家订餐约定生成、供自己家庭用餐的特殊订单；它计入制作份数，但不需要配送或记录收款。
_Avoid_: 备餐数、自用份数

**餐次容量**：
桃子为一个餐次设定的计划制作份数上限，用于计算顾客端剩余份数；它不阻止桃子开放餐次或在商家端超量操作。
_Avoid_: 硬性制作上限

**收款记录**：
桃子手工维护的订单线下收款标记，取值为“未确认收款”或“已确认收款”，不代表小程序参与或验证了付款。
_Avoid_: 平台支付状态、结算状态

**订单编号**：
Kith Inn 为每笔订单生成的短且稳定的标识，也用于在微信聊天与 Kith Inn 之间人工匹配订单；它不是微信支付订单号、支付凭证或顾客身份凭证。
_Avoid_: 订单号、对账码、支付码、付款码、交易流水号
