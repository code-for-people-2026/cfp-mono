# Triage Labels（分诊标签）

Skills 使用五个 canonical triage roles。下表将这些角色映射到本仓库 issue tracker 中的实际标签。

| Matt Pocock Skills 中的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交给 AFK Agent |
| `ready-for-human` | `ready-for-human` | 需要人类实现或处理 |
| `wontfix` | `wontfix` | 不准备处理 |

当 Skill 提到某个角色时，使用上表中对应的实际标签。

如果仓库以后采用不同的标签词汇，只需修改右侧“本仓库标签”一列。
