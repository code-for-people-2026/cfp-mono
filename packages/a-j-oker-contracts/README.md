# a-j-oker-contracts

阿 J 产品的跨端业务接口与运行时校验：消息提交、会话历史、账号资料、年龄核验、隐私授权、互动安全和投诉处理。

年龄声明、核验提交、状态响应、类型和状态文案统一在 `src/age.ts`；`AgeStatus` 从 `ageStatusSchema` 推导，避免手写类型与实际校验分叉。年龄判定和供应商调用仍在服务端，本包不执行身份查询。

本包依赖 `@cfp/base-chat-protocol` 的回复、作品和表单结构，组合为产品接口。协议包负责 AG-UI 流事件、A2UI 消息及展示结构，不依赖本包。两包均不引入 Payload、ADK、数据库或 Node 专属运行时。

依赖方向：客户端/服务端 → 业务接口 → 回复与展示协议；客户端/服务端也可直接使用展示协议。
