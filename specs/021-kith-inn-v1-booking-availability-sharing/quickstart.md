# Quickstart: 营业预订与分享定位验收

```bash

pnpm verify
pnpm --filter @cfp/kith-inn-v1-fe exec playwright test --grep '按日期生成|紧凑历史'
```

## 关键场景

1. 修改默认价，开放餐次后再改默认价，确认已开放餐次价格不变。
2. 混合选择有效和无效餐次批量开放，确认逐项结果及重复点击防重。
3. 标记整天/单餐打烊并取消；确认未设置隐藏、打烊可见，已有订单时写入被阻止。
4. 分别分享某天和某餐，确认微信卡片 payload 及公开 `batch` 路径。
5. 375×812 检查配置、部分失败、成功详情、历史、停止和归档状态；H5 自动化不得冒充真机分享验收。

## 微信真机 smoke

截至 2026-07-27 未执行，T027 保持未勾选。原因是当前环境没有可验证的微信开发者工具/真机会话；H5 的“复制入口”不作为原生小程序卡片分享证据。

具备真机后需逐项记录：

1. 分别分享某天与某餐，确认聊天中出现原生小程序卡片，标题和目标准确。
2. 顾客点击卡片后直接定位到目标日期/餐次，同时仍能看到商家当前开放的其他实时餐次。
3. 商家停止预订或打烊后再次打开同一卡片，顾客侧状态随实时数据变化。
4. iPhone 刘海/底部安全区与 Android 常见尺寸下无内容遮挡，主动作可触达。
